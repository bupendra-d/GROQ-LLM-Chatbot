# Groq LLM Chatbot

An interactive Q&A chatbot built using **LangChain, Groq-hosted LLMs, and Streamlit**.

## Features

- Select from available hosted LLMs
- Adjustable temperature and maximum response tokens
- LangChain prompt templates and output parsing
- Interactive Streamlit interface

## Tech Stack

Python · LangChain · Groq API · Streamlit

## Setup and Usage

**1. Clone the repository:**

```bash
git clone https://github.com/YOUR_USERNAME/groq-llm-chatbot.git
cd groq-llm-chatbot
```

**2. Install dependencies:**

```bash
pip install -r requirements.txt
```

**3. Configure your API key:**

Create a `.env` file using `.env.example` as a reference and add your Groq API key.

**4. Run the application:**

```bash
streamlit run app.py
```
